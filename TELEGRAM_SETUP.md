# Приём заявок в Telegram

Сайт отправляет формы через `api/telegram.php`. Токен бота и Chat ID не передаются в браузер и читаются PHP из скрытого файла `.env`.

## Настройка на хостинге с PHP

1. Соберите сайт командой `npm run build` и загрузите содержимое папки `dist` в корневую папку сайта на хостинге (`public_html`, `www` или аналогичную).
2. В менеджере файлов включите отображение скрытых файлов.
3. В корне загруженного сайта переименуйте `.env.example` в `.env`.
4. Откройте `.env` и заполните:

   ```dotenv
   TELEGRAM_BOT_TOKEN=новый_токен_от_BotFather
   TELEGRAM_CHAT_ID=ваш_chat_id
   ```

5. Сохраните файл и отправьте тестовую заявку с сайта.

Предпочтительный и более безопасный вариант — разместить `.env` на один уровень выше корневой папки сайта. Обработчик автоматически ищет его и там. Если `.env` находится в корне сайта на Apache, включённый `.htaccess` запрещает скачивание файла через браузер.

## Важно

- Хостинг должен поддерживать PHP 7.4 или новее и исходящие HTTPS-запросы.
- GitHub Pages не выполняет PHP и не поддерживает секретные серверные переменные. Для этой реализации нужен обычный PHP-хостинг.
- Бот должен быть добавлен в выбранный чат. Для личного чата сначала отправьте боту `/start`.
- Токен, который ранее был опубликован на скриншоте, необходимо отозвать в BotFather и создать новый.
