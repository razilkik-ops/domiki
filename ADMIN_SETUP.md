# Админка цен и описаний

Админка открывается по адресу `https://ваш-домен/admin.html` и работает на том же PHP-хостинге, что и приём заявок в Telegram.

## Настройка

1. В корне сайта (на одном уровне с папкой `api`) или на один уровень выше откройте скрытый файл `.env`.
2. Добавьте строку с длинным уникальным паролем:

   ```env
   ADMIN_PASSWORD=ваш-длинный-уникальный-пароль
   ```

3. Убедитесь, что PHP может записывать файлы в папку `data`. Обычно права `755` для папки достаточно.
4. Откройте `/admin.html`, войдите и сохраните изменения.

Файл `.env` уже закрыт от просмотра правилом в `.htaccess`. Не используйте пароль от почты, Telegram или других сервисов.

## Вариант с хешем пароля

Вместо открытого пароля можно использовать PHP-хеш. Создайте его командой:

```bash
php -r "echo password_hash('ваш-пароль', PASSWORD_DEFAULT), PHP_EOL;"
```

Затем сохраните результат в `.env`:

```env
ADMIN_PASSWORD_HASH=$2y$...
```

Если заполнены обе переменные, админка использует `ADMIN_PASSWORD_HASH`.

## Защита входа и полей

- После пяти последовательных неверных паролей вход с этого IP-адреса блокируется на один час. Счётчик хранится на сервере и не сбрасывается очисткой cookie или сменой браузера.
- Успешный вход обнуляет счётчик ошибок для этого IP-адреса.
- Цены проходят числовую проверку на сервере. Описания принимаются только как корректный обычный текст: HTML/PHP-теги и управляющие символы отклоняются.
- На публичных страницах описания вставляются через `textContent`, поэтому сохранённый текст не выполняется как HTML или JavaScript.

Cloudflare распознаётся автоматически по официальным диапазонам адресов, и исходный IP берётся из `CF-Connecting-IP`. Если сайт находится за другим reverse proxy, задайте в `.env` диапазоны адресов именно доверенного прокси и используемый им заголовок:

```env
ADMIN_TRUSTED_PROXY_CIDRS=точный-IP-или-CIDR-прокси
ADMIN_CLIENT_IP_HEADER=CF-Connecting-IP
```

Допустимы только заголовки `CF-Connecting-IP` и `X-Real-IP`. Без списка доверенных прокси сервер намеренно использует `REMOTE_ADDR` и не доверяет подделываемым заголовкам запроса.

Если владелец случайно заблокировал себя и ждать час нельзя, удалите через файловый менеджер файл `data/admin-login-state.json`. Он будет создан заново при следующей попытке входа.

## Где хранятся изменения

Исходные данные лежат в `data/site-content.json`, а изменения админки сохраняются отдельно в `data/site-content.local.json`. Поэтому обычное обновление файлов сайта не затрёт уже сохранённые цены и описания. Перед полной очисткой папки сайта сохраните резервную копию файла `site-content.local.json`.
